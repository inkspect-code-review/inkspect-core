# Inkspect Core

Shared authentication, database and domain services used by the Inkspect API and dashboard.
Applications import this Node.js library as `@inkspect/core`.

## Local development

Use Node.js 22.13 or newer and run the checks from this checkout.

```sh
npm ci
npm run audit
npm test
npm run build
```

To run a complete instance, use the [self-hosted distribution](https://github.com/inkspect-code-review/inkspect).
